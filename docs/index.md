# zurichjs.com knowledge

The documentation of zurichjs.com, the website of ZurichJS, as an Open Knowledge Format (OKF) v0.1 bundle. It describes how the site, the Studio and the automation are built and why. Agents start with [`AGENTS.md`](https://github.com/zurich-js/zurichjs-website/blob/main/AGENTS.md) at the repository root, which links here.

- [Conventions](/conventions/index.md): how this bundle is written and maintained
- [Systems](/systems/index.md): the repository, the apps, the packages, operations, testing and SEO
- [Domains](/domains/index.md): events, membership, content, partners, talk proposals, forms and donations
- [Reference](/reference/index.md): the decision record and other records kept for their history

Start here:

- [System map](/systems/overview.md): repository layout, packages, contracts and integrations
- [Local development](/systems/local-development.md): setup and the commands that are checked in CI
- [Working rules](/conventions/working-rules.md): what needs the owner, PRs, commits (binding)
- [Brand rules](/systems/design-system/brand.md) and [UI rules](/systems/design-system/ui-rules.md): binding rules for anything people see
- [Operations](/systems/operations/index.md): deploys, environment variables, rebuilds and what to do when something fails
- [Update log](/log.md): meaningful changes to this bundle
