# Outcome

`Button` has four variants: `primary`, `secondary`, `cta` and `plain` (interface controls only). A tertiary button is not decided (design system v2, owner, 12th November 2026). This Spec holds that open decision.

## Requirements and acceptance

- If added, it is a `variant` of the one `Button` (and its Preact twin), 48px like every button, with an `inverse` form for black surfaces.
- It is shown in the `/design` gallery and listed in [Components](/systems/design-system/components.md).
- It follows the brand rules: pill shape, no new accent colour.

## Affected concepts

- [Components](/systems/design-system/components.md) (Buttons)
- [Design system package](/systems/design-system/overview.md)

## Open decisions

- Whether a tertiary button is needed at all, and its look. No proposal is recorded.
