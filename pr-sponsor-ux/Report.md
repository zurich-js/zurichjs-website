## Policy under discussion

The present card flow chooses an immediate prorated upgrade for a higher tier on the same cycle and a future change for other combinations. Stripe receives `error_if_incomplete` for an immediate charge. The current implementation has no durable failed-upgrade collection workflow or pending-request path for an unreadable Stripe schedule. A board follow-up, an optional immediate upgrade, and a next-renewal default require a separate policy and implementation decision. An unquoted immediate change cannot display an exact provider invoice amount before confirmation.
